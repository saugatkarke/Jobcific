# Agent instructions

- Never use em dashes (U+2014) or en dashes (U+2013) in files, comments, commit messages, PR text, docs, UI copy, or chat replies. Use a comma, colon, period, parentheses, or a normal hyphen instead. ASCII hyphen-minus (`-`) is allowed only in code, flags, kebab-case names, and numeric ranges. See `.cursor/rules/no-em-dashes.mdc`.
